# Lesson 01 复利计算器

作者：朱雅莉（20251030063，金融学+计算机科学与技术双学士学位班级）

本项目用于课堂实践：计算年复利、月复利和单利，并比较不同方式的本息终值。

## 运行

在 Python 3.10 或更新版本。在本目录运行：

```bash
python compound_calculator.py
```

输入本金、年利率（小数形式）和年限。程序会输出年复利/月复利以及单利对照表，并拒绝非正本金、非正年限和负利率。

## 公式

复利终值：`FV = PV × (1 + r/n)^(n×t)`；单利终值：`FV = PV × (1 + r×t)`。

## 检查点

本金 10000、年利率 5%、3 年、每年复利 1 次，年复利终值应为 11576.25 元。30 年复利与单利差额约为 18219.42 元。
